What moved the numbers

Only games that can touch a Brewers magic number appear here, each one annotated with exactly what it changed.

How it works

One formula, four chasers

M  =  163  −  Brewers wins  −  chaser losses
  • Each race measures the Brewers against a different chaser — which is why a Cubs loss moves the division number and nothing else.
  • A Brewers win drops all four numbers by one. It is the only result that does.
  • A Brewers loss moves nothing. Losses don't raise a magic number — they only burn a game off the schedule.
  • The 163 is 162 games plus one, because the extra game is what turns a tie into a clinch. MLB now breaks ties mathematically, so where the Brewers own the head-to-head tiebreaker the real number can be one lower.
  • If the chaser changes overnight, a number can rise even after a win. The feed says so when it happens.
